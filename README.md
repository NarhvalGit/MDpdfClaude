# Narhval Markdown Converter

Een moderne webapplicatie voor het converteren van Markdown bestanden naar HTML of PDF formaat.

## Features

✨ **Gebruiksvriendelijke Interface**
- Drag & drop functionaliteit voor eenvoudig bestand uploaden
- Klik om bestand te selecteren
- Real-time preview van het geconverteerde document

📄 **Conversie Opties**
- **HTML**: Converteer Markdown naar volledig gestylede HTML pagina's
- **PDF**: Genereer professionele PDF documenten

🎨 **Narhval Styling**
- Modern en professioneel design
- Responsive layout voor alle apparaten
- Gradient achtergronden en smooth animaties

## Technologieën

- **HTML5**: Structuur en semantiek
- **CSS3**: Moderne styling met gradients en animaties
- **JavaScript (ES6+)**: Client-side logica
- **Marked.js**: Markdown parsing en conversie
- **html2pdf.js**: PDF generatie

## Gebruik

1. **Open de applicatie**
   - Open `index.html` in een moderne webbrowser
   - Of host de bestanden op een webserver

2. **Upload een Markdown bestand**
   - Sleep een `.md` of `.markdown` bestand naar de upload zone
   - Of klik op "Selecteer bestand" om een bestand te kiezen

3. **Kies conversie formaat**
   - Klik op de HTML kaart voor HTML conversie
   - Klik op de PDF kaart voor PDF conversie

4. **Preview en Download**
   - Bekijk de preview van het geconverteerde document
   - Klik op de download knop om het bestand te downloaden

## Ondersteunde Markdown Syntax

De applicatie ondersteunt GitHub Flavored Markdown (GFM), inclusief:

- Headers (H1-H6)
- Paragrafen en tekst opmaak (bold, italic, strikethrough)
- Lijsten (ordered en unordered)
- Code blocks en inline code
- Tabellen
- Blockquotes
- Links en afbeeldingen
- Horizontale lijnen

## Installatie

Geen installatie nodig! Dit is een volledig client-side applicatie.

### Lokaal gebruiken:
```bash
# Clone de repository
git clone <repository-url>

# Navigeer naar de directory
cd MDpdfClaude

# Open index.html in je browser
```

### Op een webserver:
Upload alle bestanden naar je webserver en open de URL in een browser.

## Ontwikkeling

De applicatie is gebouwd met vanilla JavaScript en heeft geen build process nodig.

### Structuur:
- **index.html**: Bevat de UI structuur en layout
- **styles.css**: Alle styling en responsive design
- **app.js**: File handling, conversie logica en download functionaliteit
