## Features

De Narhval Markdown Converter ondersteunt verschillende Markdown elementen:

### Tekst Opmaak

- **Vetgedrukte tekst** met `**dubbele sterretjes**`
- *Cursieve tekst* met `*enkele sterretjes*`
- ~~Doorgestreepte tekst~~ met `~~tildes~~`
- `Inline code` met backticks

### Lijsten

#### Ongeordende Lijst
- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2
- Item 3

2. Tweede stap
3. Derde stap
